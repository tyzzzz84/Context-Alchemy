# Depliant a tre ante — file per l'importazione in Canva

Copia di sola lettura di `ananda-brochure.html`, le due facce del depliant in
un unico file, una per pagina.

Il progetto vive nel repo **Ananda** (`ananda-brochure/`), che è privato:
Canva importa solo da URL pubblici, quindi il file transita da qui.
