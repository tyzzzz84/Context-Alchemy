Symbolic notation compresses the structure of prose. Three independent measurements — blind output comparison, attention entropy inside an open-weights transformer, and the model’s own verbalised reasoning — point the same way: symbolic encoding sits closer to how these systems actually work than prose does.

Semantic Arbitrage is the applied stream that turns that principle into client-ready assets.

Evidence

We audited 49 prompts from our own archive against the ratings they had already received.

One structural property predicted output quality: whether removing a single element would visibly collapse the composition. Length was controlled for — longer prompts did not score better. Neither did atmospheric consistency, once length was accounted for.

The rule was then tested forward. Three new images, in a register deliberately chosen outside our usual range, with the ranking registered before the images existed. The ranking held.

We don’t sell the finding. We apply it.
